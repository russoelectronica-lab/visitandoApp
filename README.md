# Agenda de Médicos (prueba)

Agenda para visitadores médicos: lista de médicos con búsqueda y filtros (especialidad, ciudad, pendientes, sin visitar, cumpleaños), ficha de cada médico con sus datos, registro de visitas y notas con fecha, pendientes y respaldo a archivo o Excel.

Es una sola página (`index.html`). Los datos se guardan en el navegador de cada teléfono: nadie más los ve.

Arranca con 6 médicos de ejemplo que se borran con el botón **Borrar ejemplos**.
